## Conversion Strategy

### Phase 1: Organize & Extract Metadata
1. Read PDF metadata (author, title, publication date)
2. Rename files to standard format: `[AUTHOR]_[TITLE_SHORT]_[DATE]_[TYPE].pdf`
3. Create entry in `corpus/MANIFEST.md` with full citation

### Phase 2: PDF to Markdown Conversion
1. Use `pdfplumber` or similar to extract text
2. Detect sections, headings, paragraphs, footnotes
3. Convert to Markdown with:
   - Heading hierarchy preserved
   - Emphasis/bold detected
   - Footnotes as endnotes or separate section
   - Page numbers preserved in comments
   
### Phase 3: Enrichment
1. Extract structured metadata (author, date, publisher, page count)
2. Tag with category (CORE, SECONDARY, TERTIARY)
3. Generate brief summary (first 100-200 words)
4. Index key concepts mentioned

### Phase 4: Cross-reference to Existing Database
1. Link mentions of trials to TRIAL_EVENT entries
2. Link author citations to DEMONOLOGICAL_SCHOLAR entries
3. Link conceptual discussion to DEMONOLOGICAL_CONCEPT entries

## Conversion Tools

- `pdfplumber` for robust text extraction
- `pypdf2` as fallback for encrypted/problematic PDFs
- Custom regex for heading detection
- Footnote/endnote parsing with custom logic
