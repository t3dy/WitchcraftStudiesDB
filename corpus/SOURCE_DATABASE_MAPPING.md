# Corpus-to-Database Cross-Reference Mapping

Maps academic corpus sources to WitchcraftStudiesDB entries, enabling citations and extended discussions.

## Mapping Structure

Each corpus source can reference:
- TRIAL_EVENT entries (trials discussed)
- ACCUSED_PERSON entries (individuals mentioned)
- DEMONOLOGICAL_CONCEPT entries (theories discussed)
- DEMONOLOGICAL_SCHOLAR entries (scholars cited)
- TEXT entries (primary sources quoted)
- LOCATION entries (geographic regions)

## Integration Workflow

### Step 1: Source Conversion
1. PDF → Markdown conversion (pdfplumber)
2. Metadata extraction (author, date, pages)
3. Heading hierarchy preservation

### Step 2: Trial Reference Extraction
For each source, identify:
- Which trials are discussed?
- What pages do discussions appear on?
- What is the scholarly interpretation?

### Step 3: Concept Mapping
For each source, extract:
- Which demonological concepts are analyzed?
- What theoretical framework?
- Scholarly debate described?

### Step 4: Scholar Attribution
For each source:
- Who authored it?
- Who do they cite?
- How does it relate to other scholarly work?

### Step 5: Database Integration
Add corpus references to database entries:

```json
{
  "trial_id": "bamberg-1626-mass-prosecution",
  "scholarly_sources": [
    {
      "source_id": "clark-thinking-with-demons-2001",
      "pages": [234, 235, 236, 237, 238, 239, 240],
      "context": "Clark analyzes Bamberg prosecution as application of Bodin's demonological theory..."
    },
    {
      "source_id": "roper-witch-craze-2004",
      "pages": [120, 121, 122],
      "context": "Roper provides gender analysis of accused in Bamberg hunts..."
    }
  ]
}
```
